| 1.0、2.0 | 正常运行 | 没有改动 |

**今天的重要发现：两家的 APY 是名义口径，偏高。** 1.0、2.0 的 APY 都是扣掉协议费后 LP 实际到手的部分。核实发现 3.0 里有两家没扣：

| 协议 | 现在 | LP 实际到手 | 例子 |
| --- | --- | --- | --- |
| Robinhood 主流对（Uniswap V3） | 名义，没扣链上协议抽成 | 名义的 75%–83% | USDG/WETH 0.01%：61.3% → 46.0% |
| Raydium | 名义，官方数据和页面都是总手续费 | 一般 84%–88%，个别池远低 | ZEC/MASK：35.0% → 5.9% |

修正已写好并实测，但开关先关着，以免影响研究机和正式机的同日对比。3.0 目前不发卡、不进正式榜，这个口径还没有影响任何对外数据。

**接下来分两步上线**：11-20 先交发布包 1.0.0（只做模块拆分，结果与现在完全一致），正式机影子运行通过后启用；同时研究机打开口径修正跑 3 天，再作为规则变更单独审批（1.1.0）。

**11-17**：阶段 2 有条件签收（分类抽查 19/20）；Curve 重抽 5/5；采集拆成 6 个独立模块，新旧输出 0 差异。
