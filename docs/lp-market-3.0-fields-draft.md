## 2. 与 1.0、2.0 的对应

1.0、2.0 的卡片每张三榜（TVL / 即时手续费 APY / 7 天手续费 APY 各前 20），五列：池·费率、TVL、即时 APY、7 天 APY、最后一列（24h 成交或回本天数）。APY 都是 LP 实收口径。

| 1.0、2.0 卡片列 | 3.0 字段 | 3.0 现状 |
| --- | --- | --- |
| 池·费率 | name + fee_pct | Curve 没有费率字段；Aero、Robinhood 动态费率池费率留空 |
| TVL | tvl | 6 块都有 |
| 即时 APY | apy_now | Aero 没有；Robinhood 只有非动态费率池 |
| 7 天 APY | apy_7d | Aero、Robinhood 没有；Meteora 11-19 起有 |
| 24h 成交 | vol24 | 6 块都有 |
| 回本天数 | — | 3.0 没有，第二阶段再定 |
| 「新」标记（部署 < 30 天） | age_days | Orca 全缺，Raydium 大部分缺 |
| 池名链接 | front_url 或按地址拼 | 只有 Aero、Robinhood 的 Aero 池有 |

## 3. 第二阶段前要定的口径差异

| # | 差异 | 现状与证据 | 建议 |
| --- | --- | --- | --- |
| 1 | APY 是否 LP 实收 | Curve、Orca、Meteora 已扣成实收。**11-18 核实**：Raydium 官方 `volumeFee` = 成交 × 费率，是总手续费，Raydium 页面的 feeApr 也是总口径（24 个高成交池比值全部 1.000）；LP 实际拿 Concentrated 84%、AMM v4 88%，CPMM 还要扣创建者费（ZEC/MASK 只有 16.8%，名义 35.0% → 实收 5.9%）。Robinhood 5 个 Uniswap V3 池链上协议抽成全部开启（1/4、1/6），APY 高估 20–33% | 已实现（raydium、rh 1.1.0，开关默认关）；打开前卡片标「名义」 |
| 2 | 7 天 APY 来源 | Curve 用 Prices API 日线（至少 6 天），Orca、Raydium 用官方 7 天字段，Meteora 11-19 起用自己的 7 个日快照合计 | 同卡不混来源，表格加「7 天来源」列，与 1.0 做法一致 |
| 3 | 单日爆量门槛范围 | 任务书写「只挡 APY 榜」，代码让整池不过门槛（TVL 榜也挡）。2.0 已改成只挡 APY 榜 | 第二阶段分榜时按任务书和 2.0 改，补测试 |
| 4 | 新池门槛在 Orca、Raydium 上基本不生效 | Orca 官方接口不给建池时间；Raydium 72% 的池 openTime 为 0 | 缺建池时间时不挡、不标「新」，表格写「建池时间未知」；需要时可用链上首笔交易补，第二阶段评估成本 |
| 5 | Curve 没有费率字段 | getPools 也没有费率字段（11-18 核实）。改读链上 `fee()`，和已在读的 admin_fee 同一公共节点：129 池读到 125；与页面一致（3pool 0.015%、ETH/stETH 0.01%、Yield Basis WBTC 1.30%）。只有约一半池与实收手续费推出的费率差 ≤ 5%，因为很多新池失衡时自动加价 | 已实现（curve 1.1.0，开关默认关）。费率列显示「池费率」，APY 仍用实收手续费 |
| 6 | Aerodrome 没有池级手续费 | 动态费率，GeckoTerminal 不给 | 只进 TVL 榜和成交榜（决策 #16）；Aero LpSugar 合约评估后可能补上 |
| 7 | 股票和商品池在 3.0 很少 | 11-18 过门槛：Aero 8、Orca 2、Raydium 18、Meteora 5；Robinhood 股票池归 2.0 | 分榜方式第二阶段定：单独一榜，或在代币榜里打标 |

## 4. 降级规则（草案）

| 情况 | 卡片和表格怎么显示 | 排序 |
| --- | --- | --- |
| 字段没有数据源（Aero 手续费、Orca 建池时间） | 「暂缺」，说明里写原因 | 不进依赖该字段的榜 |
| 字段被规则主动留空（动态费率池的费率和 APY） | 「动态费率，未取」 | 不进 APY 榜 |
| 当天取数失败 | 整个模块显示「失败」，不用前一天的值顶替 | 该模块当天不出榜 |
| 7 天字段天数不够 | 「数据不足」 | 不进 7 天 APY 榜 |
| 估算值（如 Meteora 的 fee24 × 7） | 只用于过滤，不显示、不排序 | — |
| APY 口径未核实为实收 | 数值后加「名义」 | 照常排序，说明里写明 |
| 链接拿不到 | 池名不可点 | — |

链接补齐：Curve 用 getPools 返回的官方池页链接（`poolUrls`，curve 1.1.0 已实现，开关默认关）；Orca、Raydium、Meteora 的官方池页地址格式待核实，核实前链到 GeckoTerminal 或不加链接。
