# LP 市场监控 3.0 · 内部阶段 3（收尾）设计草稿

2026-11-17 · Julywa · 研究机（tool-03）

阶段 3 是第一阶段的最后一步：让 3.0 的数据层能长期自己运转，并给产品第二阶段准备好字段清单。共 4 项：标签和股票名单定期刷新、扫描覆盖率每天自动重算、跨协议字段与降级规则、自动化登记。**本文只是设计**，阶段 1 签收后才开始写代码。所有新任务先在研究机用 `com.july.lab.*` 跑满 3 天，验证后进发布包，再由 1 号机影子运行上线。

## 1. 标签和股票名单定期刷新（第一项，阶段 2 签收条件）

**为什么**：标签缓存不会自动更新。11-16 有 6 个正常池被误挡；11-17 刷新后的第二天，Raydium 又有 14 个新代币不在缓存里，BLESS/USDC 被误标「待分类」（阶段 2 分类抽查 19/20 的那一池）。

| 项 | 设计 |
| --- | --- |
| 数据源 | CoinGecko 公开接口 `/coins/solana/contract/<mint>`（🔴 第三方；11-17 实测免 key 可用，18 次查询全部成功） |
| 刷新哪些代币 | 缓存里已有的（约 230 个）+ 最近 7 天三家输出里出现、但不在缓存或状态为 unknown/error 的 |
| 频率 | 每周一次全量（周日 06:00）+ 每天一次增量（只查新出现的代币，06:30，通常 0–20 个） |
| 限速 | 每次查询间隔 7 秒；429 等 60 秒再试，最多 3 次。全量约 30–40 分钟，增量 1–3 分钟 |
| 写入 | 先写临时文件，校验格式后原子替换；替换前备份旧缓存（保留 8 份）。查询失败的代币保留旧值，标 `stale_since`，**不改成 unknown** |
| 产出 | `labels-diff-<日期>.md`：新增、标签变化（尤其 ok↔meme）、仍失败的代币 |
| 股票名单 | 现在用的是 11-11 的快照。同一任务每周按 15 个 CoinGecko 分类重拉成员；成员有变化时写进 diff，不自动删除旧成员（防止 CoinGecko 临时下架造成误判） |
| 告警 | 只写文件和日志；整合日报的「需要注意」里列出当天待分类代币数 |
| 隔离 | 研究机写自己的缓存副本 `out/lab/refdata/`。模块通过 `LP3_SOL_LABELS` 环境变量读取，不碰 `mvp3/stage0/out/` |
| 待确认 | 11-16 用的刷新脚本不在仓库里（在之前 Grok 会话的工作区）。有的话拿来参考，没有就重写 |

## 2. 扫描覆盖率每天自动重算

**为什么**：任务书里的 35.2% 和 49.9% 是 11-16 手工跑 `stage0/coverage_scope.py` 算的。「进榜 / 筛掉」的拆分还在用 11-11 的旧数（`coverage-pool-2026-11-11.json`，任务书 §7 风险表）。

| 项 | 设计 |
| --- | --- |
| 输入 | DefiLlama `overview/fees`、`overview/dexs`、`/protocols`（🔴 第三方，只作分母），加上当天 6 个模块的输出 |
| 拆分 | 「进榜 / 规则筛掉 / 扫描范围外」改用当天模块输出计算，不再读 11-11 的文件 |
| 频率 | 每天一次，放在 stage2 之后（10:50），只读文件、只写 `coverage/scope-<日期>.json` 和 `.md` |
| 先干跑 | 前 3 天同时跑旧脚本和新逻辑并对比；口径对上之后，整合日报才显示新数 |
| 告警 | 扫描覆盖率比前 7 天均值变化超过 3 个百分点时写进日报「需要注意」（阈值待 July 定） |

降级规则（草案，产品第二阶段任务书定稿）：

| 情况 | 卡片和表格怎么显示 | 排序 |
| --- | --- | --- |
| 字段没有数据源（Aero 手续费、Orca 建池时间） | 显示「暂缺」，说明里写原因 | 不进依赖该字段的榜（Aero 不进 APY 榜） |
| 字段被规则主动留空（动态费率池的费率/APY） | 显示「动态费率，未取」 | 不进 APY 榜 |
| 当天取数失败 | 显示「失败」，不用前一天的值顶替 | 整个模块当天显示「失败」 |
| 7 天字段天数不够 | 显示「数据不足」 | 不进 7 天 APY 榜 |
| 估算值（如 Meteora 的 fee24×7） | 加「估」字标记 | 只用于过滤，不用于排序 |

单日爆量门槛：代码里是整池不过门槛，任务书写的是「只挡 APY 榜」（模块化任务书 §8 #1），产品第二阶段分榜时一并改，届时补测试。
