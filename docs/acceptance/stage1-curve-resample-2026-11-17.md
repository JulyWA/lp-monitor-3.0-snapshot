## 两个发现

1. **curve.fi 页面上有两个 TVL。** 标题上的 TVL 来自 Prices API，资产明细里的「USD Total」来自链上余额。普通池两者差不多；Yield Basis 池标题是 $70.11M，明细和链上都是 $40.2M，**标题高了 75%**。11-16 改用 getPools 的决定是对的。以后人工核对 Curve 一律看资产明细合计，不看标题。
2. **PayPool 实际费率高于基础费率。** 这类 stable-ng 池在失衡时会自动把费率调高。Prices API 记的是实际收到的手续费，此刻同样算出 0.0116%，所以我们的 APY 反映的是真实收入，不是错误。
