# Aero 与 Aerodrome 旧版 · Base 模块（lp3/modules/aero）

版本 1.0.0 · 时段 第一步 · 08:20（rh 之前，两者串行） · 变更见 `CHANGELOG.md`。

## 数据源

| 用途 | 接口 | 性质 |
| --- | --- | --- |
| 池列表、TVL、24h 成交 | api.geckoterminal.com（7 个交易所编号，按成交前 10 页） | 第三方聚合 |
| 掉出列表的大池复查 | GeckoTerminal pools/multi | 第三方聚合 |
| 复查池能定价一侧、采全比分母 | coins.llama.fi、api.llama.fi | 第三方，只影响采全比 |

## 规则

门槛（`config.json` 的 `rules` 段，初值与 1 号机提交 fe9f8e2 相同）：TVL ≥ $50 万；部署 ≥ 7 天；24h 成交 ≤ 3 × 近 7 天日均（现为整池不过门槛，见 3.0 任务书风险表）。资产类别：任一侧在股票和商品名单里，归「股票和商品」。

Aero 专有：dex 编号以 aero- 开头记「Aero」，以 aerodrome- 开头记「Aerodrome 旧版」；池名去掉费率后缀；旧版池 24h 成交 ÷ TVL < 0.1% 标「旧版沉睡」，照常进榜；前一天 ≥ $50 万、当天掉出列表的池按地址复查补回。

## APY 口径

没有。动态费率，GeckoTerminal 不给池级手续费，只进 TVL 榜和成交榜（决策 #16）。

## 输出字段

池地址、池名、协议（Aero / Aerodrome 旧版）、TVL、24h 成交、部署天数、前端链接（app.aero.xyz 或 aerodrome.finance）、旧版沉睡标记。 另有追溯块：模块版本、提交号、状态、采集时间、接口请求统计。字段覆盖率见《字段清单与降级规则》。

## 开关（1.1.0，默认关）

无。

## 已知限制

- 数据源最不稳：同一批池几小时内 TVL 波动可达 ±50%–120%（11-17、11-18 两次实测）
- 高周转 CL 池 TVL 被低估约 10%
- 免费档限速，每天被 429 限流约 9 次（重试后成功）
- 官方 LpSugar 合约可作替代，阶段 3 之后评估

## 改动规矩

- 改规则只改本模块的 `config.json` 或 `rules.py`，升版本号，写 CHANGELOG，补测试，并跑回放对比。
- 规则或数据源变更要 July 批准。
