## 规则

门槛（`config.json` 的 `rules` 段，初值与 1 号机提交 fe9f8e2 相同）：TVL ≥ $50 万；部署 ≥ 7 天；24h 成交 ≤ 3 × 近 7 天日均（现为整池不过门槛，见 3.0 任务书风险表）。资产类别：任一侧在股票和商品名单里，归「股票和商品」。

Solana 标签（读本地缓存，运行时不调 CoinGecko）：任一侧有 meme 标签 → 存档不进榜；代币不在缓存或上次查询失败 → 挡在榜外，标「代币分类待更新」；CoinGecko 未收录且 7 天手续费 ÷ TVL < 0.01% → 按假 TVL 存档。稳定币、SOL 及质押衍生、BTC/ETH 包装视为锚定，不查标签。

Meteora 专有：官方黑名单池挡在榜外；没有 7 天字段，11-19 起若前 7 个连续日本模块快照齐全，7 天手续费 = 7 日合计，否则低费过滤用 24h × 7 估算（估算值只用于过滤）。

## APY 口径

即时 = 24h 手续费 × (1 − 协议手续费占比) × 365 ÷ TVL；7 天 APY 11-19 起有。LP 实收口径。

## 输出字段

池地址、池名、协议（DLMM / DAMM v2）、基础费率、TVL、24h 成交和手续费、LP 分成、即时 APY、建池时间、代币是否认证、Solana 标签。 另有追溯块：模块版本、提交号、状态、采集时间、接口请求统计。字段覆盖率见《字段清单与降级规则》。

## 改动规矩

- 改规则只改本模块的 `config.json` 或 `rules.py`，升版本号，写 CHANGELOG，补测试，并跑回放对比。
- 规则或数据源变更要 July 批准。
