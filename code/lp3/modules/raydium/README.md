# Raydium · Solana 模块（lp3/modules/raydium）

版本 1.1.0 · 时段 第二步 · 10:20 · 变更见 `CHANGELOG.md`。

## 数据源

| 用途 | 接口 | 性质 |
| --- | --- | --- |
| 全部字段 | api-v3.raydium.io/pools/info/list（按 TVL 降序分页） | 官方 API |
| 能定价一侧（采全比） | coins.llama.fi | 第三方，只影响采全比 |
| 采全比分母 | api.llama.fi | 第三方，只作分母 |

## 规则

门槛（`config.json` 的 `rules` 段，初值与 1 号机提交 fe9f8e2 相同）：TVL ≥ $50 万；部署 ≥ 7 天；24h 成交 ≤ 3 × 近 7 天日均（现为整池不过门槛，见 3.0 任务书风险表）。资产类别：任一侧在股票和商品名单里，归「股票和商品」。

Solana 标签（读本地缓存，运行时不调 CoinGecko）：任一侧被 CoinGecko 归入 meme 类别 → 按非研究对象 N2（投机标签代币池）存档，不进榜；代币不在缓存或上次查询失败 → 挡在榜外，标「代币分类待更新」；CoinGecko 未收录且 7 天手续费 ÷ TVL < 0.01% → 按非研究对象 N3（假 TVL 池）存档。稳定币、SOL 及质押衍生、BTC/ETH 包装视为锚定，不查标签。

采全比只算 DefiLlama 能定价的一侧，豁免 80% 线（11-16 批），照算照报。

## APY 口径

即时 = 官方 24h volumeFee × 365 ÷ TVL；7 天 = 官方 7 天 volumeFee × 52 ÷ TVL。**名义口径**：11-18 核实 volumeFee 是总手续费，Raydium 页面的 feeApr 也是总口径；LP 实际拿 Concentrated 84%、AMM v4 88%，CPMM 还要扣创建者费。

## 输出字段

池地址、池名、类型（Concentrated / Standard）、费率、TVL、24h/7 天成交和手续费、两种 APY、建池时间（大部分为 0）、两侧数量、Solana 标签。 另有追溯块：模块版本、提交号、状态、采集时间、接口请求统计。字段覆盖率见《字段清单与降级规则》。

## 开关（1.1.0，默认关）

| 开关 | 作用 | 当前值 |
| --- | --- | --- |
| `lp_share_mode` | 设为 net 时按池类型扣成 LP 实收（11-18 实测：过门槛 62 池，50 个 84%、9 个 88%，ZEC/MASK 只有 16.8%） | `"nominal"` |

M4（至 11-20）结束后在研究机打开，跑满 3 天后随 1.1.0 发布（3.0 模块化任务书决策 #9）。

## 已知限制

- 72% 的池 openTime 为 0，「部署满 7 天」门槛大部分不生效
- 假 TVL 多，靠低费未收录过滤（每天排除约 50 池）
- 一批新代币几乎每天出现，标签缓存要定期刷新（阶段 3 已上线干跑）

## 改动规矩

- 改规则只改本模块的 `config.json` 或 `rules.py`，升版本号，写 CHANGELOG，补测试，并跑回放对比。
- 规则或数据源变更要 July 批准。
